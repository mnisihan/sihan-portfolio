Sihan Portfolio Website — updated with Book Hut, Doheem, Travel Sundarban and Group de Madventurers logos.

DEPLOY TO NETLIFY:
1. Extract the ZIP.
2. Open your Netlify project.
3. Select Drop new files and upload the extracted sihan-portfolio folder (or drag the folder to the deploy area).
4. Confirm the latest production deployment is live and public.

All images are included in assets/ and work without external hosting.
